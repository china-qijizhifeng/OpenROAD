v2 为密度融合/局部累加版本；v3 为最终 WA CSR/缓存边界整改版本。
所有时间只度量 global_placement，不包含导出状态、合法化或时序统计。

## v3 最终重复计时

原版第 0 个样本复用上表同一固定输入的原始验收日志（逐份重新核对 SHA-256 与输出状态）；
候选第 0 样本后，另外两轮按相反顺序交替原版/候选，各配置最终每种二进制各 3 次。
因此原版首样本与最终候选不在同一时间窗口，不将其描述为同时配对的三轮。

ibex_core 有 SDC：另比较 detailed_placement、check_placement、WNS/TNS、面积、HPWL。
最终 large01/large01-rd/large02 的全部 native/v3 样本由独立 high worker 运行，结果另表，不混合机器样本。
其余配置只有 LEF/DEF：只比较完整 cell/port/net 状态、面积和 HPWL，不宣称时序或合法化验收。
全部正式计时均不加载采样器，OpenSTA 固定 1 线程，GPL 1/8 线程。
